# 小食痰记本地管理后台搭建

## 目标与范围

按用户指定的 Cool Admin Midway 8 和 Cool Admin Vue 8 搭建本地管理后台，使用 sub2api-US 上的独立 MySQL 开发数据库。交付可访问的登录、管理员、角色、菜单、权限、日志和基础管理页面。

本次为后续业务管理建立基础。App 现有 FastAPI、PostgreSQL、AI 服务保持独立，饮食、抽烟、跑步和 HealthKit 业务数据的管理接入另行开发。

## 实施步骤

1. 引入前后端源码，保留 MIT 许可和上游版本记录，安装并锁定依赖。
2. 在服务器创建独立 MySQL 8.4 容器、卷、数据库和专用用户。仅监听服务器回环地址，限制内存，通过 SSH 隧道供本机访问。
3. 环境变量配置数据库、Cookie 和 JWT 密钥。生成独立管理员密码，私密配置不进入 Git。
4. 提供本地启动、状态和停止命令。前后端固定监听本机地址，首页标明当前接入范围。
5. 验证数据库初始化、验证码登录、权限菜单、基础页面、前端构建和后端编译，进行独立代码审查。

## 验收

- 本机 http://127.0.0.1:9000 可登录并访问权限管理页面。
- 本机后端 http://127.0.0.1:8002 的受保护接口需要有效登录。
- 数据保存在独立 MySQL，数据库无公网监听，既有服务不被修改。
- 停止和重新启动后仍可登录，管理员密码不会被初始化覆盖。
- 源码、依赖锁和说明完整，私密配置和运行产物均被忽略。
