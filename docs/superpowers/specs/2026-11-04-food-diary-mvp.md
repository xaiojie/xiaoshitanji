# 食记 MVP

## 目标

iPhone 中文饮食记录应用。文字、相册图片和拍照输入经 DeepSeek 分析后，用户确认份量和营养数值，保存到本机并查看每日汇总。

## 本轮实现决定

- 用户授权直接开发。采用首轮视觉稿的浅色、鼠尾草绿和清晰内容层，Liquid Glass 用于原生导航及主要操作。
- SwiftUI，iOS 26 起，原生 Xcode 工程，核心逻辑用本地 Swift Package 复用和测试。
- DeepSeek 官方接口 https://api.deepseek.com/chat/completions，默认 deepseek-flash。2026-11-04 查阅官方文档确认该模型支持图片及 JSON 输出。
- 个人使用模式，API Key 在应用内输入并保存在 Keychain。饮食文字和压缩后的照片经用户点击分析后发送给 DeepSeek。
- 记录采用版本化 JSON 原子写入。保存成功后更新界面，失败时保留草稿。读取失败时阻止覆盖已有文件。
- 食物保存实际食用克数及每 100g 营养数值，调整份量自动重算。所有 AI 数值标注为估算。
- 数据包含原始输入、图片、模型名、估算说明、餐次、时间、食物和营养数值。
- 空白安装无演示餐。无 Key 时仍支持手动记录。每日热量参考目标由用户自选，默认关闭。
- 首版提供今天、7 天趋势和设置，允许补记、编辑、删除。
- 用户指定使用真实 iPhone 验证。使用 iPhone SDK 编译和本机核心测试，到安装阶段连接手机。

## 验收

1. 构建生成可供签名的 iPhone App。
2. 核心测试覆盖份量计算、输入校验、保存重开、编辑删除、损坏文件保护和 DeepSeek 请求/响应边界。
3. 真机验证文字或照片输入、编辑、保存、重启回读。实时 API 验证需要用户自己的 Key。

## 后续

健身、HealthKit、云同步和独立营养数据库列为后续迭代。MVP 的营养密度来自 AI 估算，并保留说明供用户核对。
