# 户外跑步与奶蛙运动手账

记录日期为 2026-11-05，用户已选定第三套原型并授权按三个阶段实现。新增公里目标跑和 Apple 健康心率。手机当前断开，纯逻辑验证与通用 iPhone 构建先完成，户外定位与设备交互由后续真机验证。

## 体验与范围

健身位于趋势之后。第三套黄色运动手账首页显示本周跑步次数、里程、时长、周历与运动记录，主操作为开始跑步。新增四张保持原始角色外观的透明奶蛙素材，分别用于休息、拉伸、跑步与喝水。

跑前选择自由跑或公里目标跑。目标支持 0.1–200 公里，达到目标提醒一次，继续记录由用户结束。跑步支持精准 GPS、地图路线、秒级计时、暂停、继续、结束与保存。地图标记起终点并在暂停、断点或异常定位处拆分线段。结束展示有效距离、时长、平均配速、公里分段和体感。

## 数据与可靠性

运行会话独立于页面，使用 Core Location、后台定位活动和 MapKit。记录时间使用时间戳而非计数器累计。轨迹过滤过期位置、低精度和不合理跳点。定位断开和暂停之后的新点作为新线段起点。草稿定期原子写入，异常重启只恢复到最近持久化时刻，用户选择继续或保存。

跑步精确数据与轨迹存入独立本机 RunArchive，记录 ID 关联现有 WorkoutRecord。WorkoutRecord 的可选 runMetrics 保存精确时长、距离、平均与最高心率及估算消耗摘要，既有字段继续满足旧客户端约束，保留 schema 5 兼容性。旧客户端显示兼容摘要，新客户端聚合精确指标。目标、轨迹与细粒度心率归属原设备，页面明确显示。保存按同一 ID 幂等重试，删除处理记录和本机轨迹。无有效距离时配速为未知。体重可用时计算标注为估算的活动消耗。

## 心率与分析

心率从已授权的 Apple 健康读取，仅接受本次跑步有效时间区间内的样本，处理暂停区间、多来源与重复样本。界面注明来源和测量时间，过期样本显示最近读数。支持跑后刷新以接收延迟同步的设备样本，显示平均、最高和曲线。

单次跑步 AI 通过现有后端和 AIConsent，发送统计、已记录的当日营养及明确选择的身体信息。发送心率统计需本次明确选择，坐标与原始心率样本留在本机。建议引用记录覆盖情况，避免把缺失数据视作零，避免依据未知年龄或性别给出心率分区。周期汇总复用已保存训练摘要。

运动列表对唯一且高置信的同场本机/健康记录合并，来源保持可见。消耗保持已有健康优先口径，全天活动能量与训练消耗按包含关系处理。
