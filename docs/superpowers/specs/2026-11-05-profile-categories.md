# 个人主页分类与拟物图标

用户要求直接开发并构建，手机已断开，回来后自行测试。

首页保留个人资料、汇总分析和四项今日概况。健康档案按身体测量、活动与训练、心脏与体能、睡眠与听力四类进入二级页，原来的完整指标、七日图表、训练列表和来源说明按分类展示。饮食摄入从今日概况进入，能量目标及其他常用工具放入紧凑入口。

这是本轮采用的信息分组。沿用 SwiftUI NavigationStack、现有测量与图表视图和数据来源，缺少数据时显示未知与连接入口。各分类可下拉刷新，已有资料编辑、体重、训练、观察、坚持、同步、设置和汇总分析入口全部保留。

晚餐新增 FoodDinner，餐食四类默认图与快捷记餐统一使用真实碗装餐食素材。个人主页和健康分类采用透明背景拟物图标，沿用暖白、黄色、橄榄绿和现有奶蛙视觉。导航箭头与系统菜单使用原生控件。

数据模型及持久化格式沿用现有实现。验证包括图标资源完整性、分类覆盖、完整逻辑回归、原数据读取、iPhone Debug 构建和 Release 归档。真机安装和交互在用户连接后完成。
